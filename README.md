# QA-тест Demoblaze

Автоматизация тестового задания на JavaScript с Playwright и Chromium.
Код сценария: [tests/cart.spec.js](tests/cart.spec.js).

## Сценарий

1. Открыть https://www.demoblaze.com/.
2. Нажать **Samsung galaxy s6**.
3. Нажать **Add to cart** на странице товара.
4. Нажать **OK** в уведомлении.
5. Нажать **Cart** в шапке сайта.

**Проверка:** в корзине ровно одна строка товара, её название — **Samsung galaxy s6**, и строка видна.

Тест выполняется от имени гостя в новой сессии браузера. Авторизация и предварительная очистка корзины не требуются.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `tests/cart.spec.js` | Действия пользователя и проверка корзины |
| `playwright.config.js` | Адрес сайта, браузер и таймауты |
| `package.json` | Зависимость Playwright и команды запуска |
| `package-lock.json` | Зафиксированные версии зависимостей |
| `.gitignore` | Исключение зависимостей и результатов запуска из Git |

## Запуск

Нужны Node.js 24 с npm и доступ к интернету. В папке проекта выполнить:

```bash
npm ci
npx playwright install chromium
npm test
```

Для запуска с видимым окном браузера: `npm run test:headed`.
На Linux браузер и системные зависимости устанавливаются командой `npx playwright install --with-deps chromium`.

## Особенности реализации

- Ссылки находятся по роли и точному видимому названию.
- Ожидание браузерного уведомления начинается до клика **Add to cart**. Тест нажимает **OK** через `dialog.accept()` и затем переходит в корзину.
- Проверяются все строки товаров: лишний товар или дубликат приводят к падению теста. Заголовок таблицы в подсчёт не входит.
- Playwright автоматически ждёт готовности элементов и выполнения проверок. Фиксированных пауз нет. Таймаут проверки — 30 секунд, всего теста — 90 секунд.

## Результат запуска

При успехе в терминале выводится `1 passed`, код завершения — `0`. При ошибке выводятся место падения и причина; код завершения ненулевой.

Тест обращается к настоящему сайту без подмены ответов. Доступность Demoblaze и его API влияет на результат запуска.
